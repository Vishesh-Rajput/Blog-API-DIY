# Web Application - API Test Run

## Overview
This web application is a **test run** of the learnings I had while creating and running my **own API**. The application is built using **Express.js** and **EJS** for templating and performs full **CRUD (Create, Read, Update, Delete) operations**.

## Technologies Used
- **Node.js** (JavaScript runtime)
- **Express.js** (Web framework for backend)
- **EJS** (Templating engine for frontend rendering)
- **Body-parser & Other Middleware**

## Setup & Installation
### Prerequisites
Ensure you have **Node.js** installed on your system.

### Steps to Run the Application
1. **Clone the repository:**
   ```sh
   git clone https://github.com/your-username/webapp-api-test.git
   cd webapp-api-test
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Run the API Server:**
   ```sh
   node index.js
   ```
4. **Run the Website Server:**
   ```sh
   node server.js
   ```
5. Open your browser and navigate to `http://localhost:3000` (or the port you have configured).

## Features
- **Create, Read, Update, Delete (CRUD) operations**
- **Separate API server (`index.js`) and website server (`server.js`)**
- **Dynamic HTML rendering using EJS**
- **Middleware for request handling**
